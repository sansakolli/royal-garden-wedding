# Aarya & Arjun — The Royal Garden

A complete responsive fictional wedding invitation, using plain HTML, CSS and JavaScript. Open index.html locally or serve this folder as a static site. No build or installation required.

## Features

- Original generated wedding photography, optimized to WebP
- Cinematic opening, parallax, scroll reveals and sticky desktop story
- Mobile layouts and reduced-motion support
- Wedding events, family introduction, photo lightbox and countdown
- Calendar invitation download
- RSVP message composer and WhatsApp sharing (no backend or automatic submission)

## Personalize

Edit names, family, story, venue and event details in index.html. Change the countdown and calendar event in app.js. Replace assets with your own photos, preserving filenames or updating their references. Change the Maps link to the actual venue. The current WhatsApp link opens a share composer without an assigned recipient; supply the actual host's WhatsApp number if direct delivery is wanted.

All people, dates and venue details are fictional. The venue link explores Lake Pichola rather than claiming a real address for the fictional Rose Palace.

## Deploy on GitHub Pages

Upload this folder's contents to the repository root. In Settings > Pages choose Deploy from a branch, main, / (root), then Save.

## Generated image prompts

1. Palace: cinematic ivory Indian palace garden at twilight, scalloped arches, cream roses with burgundy accents, candlelit reflecting pool, no people; editorial photographic realism.
2. Couple: candid Indian couple in their late twenties, burgundy silk lehenga and ivory sherwani, tender moment in a palace garden at warm dusk.
3. Hands: close-up of warm brown hands holding, henna and gold bangle, burgundy silk and ivory sherwani, dreamy cream roses and palace garden.

Google Fonts are optional external resources; system serif and sans-serif fallbacks are supplied. The site otherwise uses local assets and no animation libraries.
