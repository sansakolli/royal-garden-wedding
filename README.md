# శ్రీరస్తు — Aarya & Arjun

Cinematic Telugu wedding invitation. Plain HTML/CSS/JavaScript with no build step.

Scroll-driven mandapam opening, three pinned story scenes, Telugu text and typography, traditional events, countdown, calendar download, accessible photo dialog and WhatsApp RSVP composer. Supports reduced motion.

All people, date and venue details are fictional. RSVP prepares a message; visitors choose the recipient in WhatsApp. No responses are stored. Maps opens Vizianagaram city, not a real venue address.

Images generated with the built-in image generator and optimized to WebP:
- mandapam.webp: Andhra courtyard mandapam with mango leaves, jasmine, marigolds and brass lamps at dusk.
- mangalyam.webp: two gold pendants on turmeric thread, betel leaf, brass plate, silk and jasmine.
- talambralu.webp: red silk Telugu bride and cream dhoti groom sharing a joyful talambralu ceremony.

Edit index.html for content and app.js for the countdown/calendar date. Google Fonts load Noto Serif Telugu and Noto Sans Telugu, with system fallbacks.

Publish repository root on GitHub Pages main branch.
